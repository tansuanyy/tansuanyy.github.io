🐙 GitHub 全套详细使用教程（精美版）

GitHub 是全球最大的代码托管平台，也是程序员、开源爱好者和团队协作的核心工具。本文将为你提供从零基础到进阶的 完整 GitHub 使用流程，包含操作方法、命令和建议实践，全部整理为 Markdown，可直接复制。

一、注册 GitHub 账号

  1. 打开官网：https://github.com
  2. 点击 Sign up
  3. 填写：
    • 邮箱
    • 用户名（唯一）
    • 密码
  4. 完成 邮箱验证
  5. 可选择免费套餐（Public Repository）或付费套餐（Private Repository）

四、创建仓库（Repository）

1️⃣ 在 GitHub 网站创建

  1. 点击 New Repository
  2. 填写仓库名称、描述
  3. 选择公开或私有
  4. 初始化 README（可选）
  5. 点击 Create Repository

八、常用 Git 命令

命令 功能
git status 查看当前状态
git log 查看提交记录
git pull 从远程拉取更新
git push 推送到远程
git branch 查看分支
git checkout 切换分支
git merge 合并分支
git reset 撤销提交
git stash 临时存储修改

九、GitHub 高级功能

1️⃣ Pull Request

  • 用于团队协作
  • 可以在 PR 中讨论、审查代码
  • 审核通过后合并到主分支

2️⃣ Issues

  • 用于任务管理、Bug 跟踪
  • 可以分配给团队成员、加标签

3️⃣ Actions

  • 自动化 CI/CD
  • 自动构建、测试、部署项目

4️⃣ Projects

  • 可视化任务板
  • 支持拖拽、看板式管理

🔐 十、安全与权限

  • 私有仓库保护代码隐私
  • 添加 Collaborator 管理访问权限
  • 使用 Personal Access Token 替代密码推送
  • 开启 Two-factor Authentication 提升账号安全

🏗 十一、实用技巧

  • 使用 README.md 美化仓库首页
  • 使用 LICENSE 明确开源协议
  • 使用 GitHub Pages 部署静态网站
  • 多分支开发，保持主分支稳定
  • 定期 Pull 远程仓库，避免冲突

🌐 十二、推荐资源

  • 官方文档：https://docs.github.com
  • Git 官方文档：https://git-scm.com/docs
  • GitHub Learning Lab：https://lab.github.com

🎯 总结

掌握 GitHub 使用不仅仅是学会提交代码，更是学会协作、版本管理和项目规划。
从零开始：

  1. 注册账号
  2. 安装 Git + 配置
  3. 创建仓库 → 添加/提交 → 推送
  4. 分支管理
  5. Pull Request + Issues + Actions
  6. 持续迭代、协作开发

精通 GitHub 后，你不仅可以管理自己的项目，还能参与开源社区，提升编程与团队协作能力。
