1.1 安装 Node.js

Hexo 依赖 Node.js 运行环境，推荐安装 LTS 版本。

  • 下载地址：Node.js 官方网站

  • hexo init my-blog：创建一个名为 my-blog 的博客目录
  • npm install：安装依赖包

8. Hexo 常用命令汇总

命令 功能
hexo init [folder] 初始化博客
hexo new post “title” 新建文章
hexo clean 清理缓存
hexo g 生成静态文件
hexo s 本地预览
hexo d 部署博客
