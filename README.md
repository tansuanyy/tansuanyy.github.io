# ✨ Welcome

Welcome to my digital garden.

This repository contains the complete source code, configuration files, articles, notes, and resources that power my personal website and technical blog.

The purpose of this project is simple:

> To document knowledge, share discoveries, preserve ideas, and continuously learn in public.

Technology evolves rapidly. New frameworks appear every month, artificial intelligence reshapes industries, and open-source communities continuously push innovation forward. In such an environment, maintaining a personal knowledge repository becomes more valuable than ever.

This blog serves as both a learning journal and a public archive of everything I find interesting, useful, or worth remembering.

# ⚡ Local Development

Install dependencies:

```bash
npm install
```

Run local development server:

```bash
hexo server
```

Generate static files:

```bash
hexo generate
```

Clean cache:

```bash
hexo clean
```

Deploy site:

```bash
hexo deploy
```
